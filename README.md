# KIEL GOLD 독립 쇼핑몰

기존 도메인과 기존 서버에 의존하지 않도록 새로 구축한 독립 쇼핑몰입니다. 상품 이미지, 배너, 폰트 등 화면 자산은 모두 `public/legacy` 아래 로컬 파일을 사용하며, 기존 사이트로 연결되는 링크·리디렉션·핫링크는 사용하지 않습니다.

## 구현 범위

- 상품 274개, 카테고리 31개, 메인 배너 2개
- 반응형 홈, 상품 목록·검색·상세, 장바구니, 위시리스트, 최근 본 상품
- 회원가입·로그인·마이페이지·주문 접수·주문 조회
- 회원 포인트 사용, 취소·미입금 만료 시 복원, 배송완료 시 1회 적립
- 배송완료 후 반품·환불 시 재고·사용 포인트 복원과 적립 포인트 회수
- 관리자 상품·재고·주문·회원·설정·콘텐츠·후기·문의 관리
- Cloudflare D1 운영 데이터와 R2 신규 미디어 저장
- 요청 본문 크기·형식 검증, 로그인 속도 제한, 보안 헤더, 세션 무효화

## 로컬 실행

```bash
npm install
npm run dev
```

## 필수 운영 환경 변수

- `ADMIN_USERNAME`: 신규 관리자 아이디
- `ADMIN_PASSWORD_HASH`: PBKDF2 관리자 비밀번호 해시
- `SESSION_SECRET`: 32바이트 이상의 무작위 세션 서명 키

관리자 비밀번호 원문은 저장소에 저장하지 않습니다.

## 배포 전 외부 설정

- 새 도메인 구매 및 DNS 연결
- 공개 전에 관리자 비밀번호 교체
- 카드 결제가 필요하면 PG사 계약과 운영 키 연결
- 이메일 인증·비밀번호 복구가 필요하면 발송 서비스 연결
- 주소 자동 입력이 필요하면 공식 주소 검색 API 연결

현재 결제는 무통장입금과 회원 포인트를 지원합니다.

## 기존 서버 종료 전 필수 데이터 이관

이 저장소에는 기존 서버의 운영 데이터베이스가 포함되어 있지 않습니다. 관리자 화면에서 확인한 기존 회원과 주문 이력은 새 D1 데이터베이스로 아직 옮겨지지 않았습니다.

기존 서버는 아래 절차를 모두 마칠 때까지 종료하면 안 됩니다.

1. 기존 호스팅 업체에서 데이터베이스 전체 덤프와 업로드 파일 원본을 받습니다.
2. 회원 비밀번호 해시 호환 여부를 확인하고, 호환되지 않으면 안전한 비밀번호 재설정 절차를 준비합니다.
3. 회원·주문·주문상품·후기·문의·포인트·운영 설정을 새 데이터베이스로 가져옵니다.
4. 총 건수, 금액, 주문 상태, 재고, 포인트를 표본과 합계로 대조합니다.
5. 새 도메인에서 최종 주문·관리자 처리 테스트와 백업 복원 테스트를 완료합니다.
